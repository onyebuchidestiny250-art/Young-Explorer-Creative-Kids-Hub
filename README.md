# Young Explorer & Creative Kids Hub

This project is a multi-page educational site for kids. The home page acts as a landing page, while each major feature has its own page:

- Home: `index.html`
- Explore: `explore.html`
- Creative Corner: `creative.html`
- Games & Quizzes: `games.html`
- Challenges: `challenges.html`
- Achievements: `achievements.html`

The shared data model and `localStorage` progress remain available across all pages so the user's learning journey persists as they move around the site.
